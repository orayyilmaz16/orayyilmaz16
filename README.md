## 🏗 Mimari Prensiplerim

Yazılım geliştirirken aşağıdaki prensipleri temel alıyorum:

- ✅ **Clean Architecture** – Katmanlar arası bağımsızlık ve test edilebilirlik
- ✅ **SOLID** – Sürdürülebilir ve genişletilebilir kod tasarımı
- ✅ **Dependency Injection** – Gevşek bağlı (loosely coupled) bileşenler
- ✅ **Repository Pattern** – Veri erişim katmanının soyutlanması
- 🔄 **CQRS** – Komut/sorgu sorumluluk ayrımı (öğreniyorum)
- ✅ **RESTful API Design** – Standartlara uygun, tutarlı API tasarımı
- ✅ **Ölçeklenebilir Yazılım Mimarisi** – Büyümeye açık sistem tasarımı
