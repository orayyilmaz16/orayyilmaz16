## 🏗 Yazılım Prensipleri & Mimari Yaklaşım

- 🏛️ **Clean Architecture** — Bağımsız katmanlar, domain odaklı tasarım ve maksimum test edilebilirlik
- 💎 **SOLID Prensipleri** — Değişime açık, sürdürülebilir, modüler ve temiz nesne yönelimli kod tasarımı
- 🔌 **Dependency Injection (DI)** — Gevşek bağlı (loosely coupled) sistemler ve test edilebilir servis kurgusu
- 🔄 **Repository & Unit of Work** — Veri erişim katmanının soyutlanması ve güvenli transaction yönetimi
- ⚡ **RESTful API Standartları** — Tutarlı HTTP durum kodları, doğru uç nokta yapıları ve DTO desenleri
- 🛡️ **Defensive Programming & Validation** — Güçlü veri doğrulama, loglama ve hata yönetimi
